# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version packages and create changelogs. Each time you merge code into this repository, you can decide what kind of change happened, and therefore what type of bump the packages should get. It is not automatic, as doing so would be overly complex. As such, we use this step-by-step process:

## Adding a changeset

Whenever you've made changes that you want to be reflected in the published packages, you should add a changeset by running `npm run changeset` in the root of the repository.

The CLI will walk you through the process of creating a changeset based on the packages changed and the semver bump type for those packages.

## Releasing a changeset

When you're ready to do a release, you can run `npm run version-packages`. This will bump the versions of the packages the previous `changesets` added and remove the changeset files.
